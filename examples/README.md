# SOPRA Examples

This directory contains example notebooks and demo data for the SOPRA model.

## Files

- **SOPRA_Demo.ipynb**: Main demonstration notebook showing SOPRA model usage
- **SOPRA_Demo_backup.ipynb**: Backup copy of the demonstration notebook
- **stations.txt**: Station metadata for demo runs

## Usage

To run the demo notebook:

1. Ensure the environment is activated: `source venv/bin/activate`
2. Start Jupyter: `jupyter notebook SOPRA_Demo.ipynb`
3. Or execute from command line: `make test-notebook` (from project root)

## Data Sources

The demo uses meteorological data from `../data/input/sopra_in/` directory.
